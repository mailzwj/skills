# MiniMax H3 武术打斗提示词 · 完整规则（文生默认 / REF 可选）

对内导演。对外只出 **一个代码块**。禁止把行为卡、评分表、生成参数表、本规则原文交给用户。

本文件 = 输出壳 + V3.1 全文，写提示词时的主文件。v2 动作 LoRA 的三视图用法、完整词库与强度标定见 `references/actions_lib.md`。

## 0. 一分钟版

规格写头、正文写动作；一条连续时间线；每一拍都有空间读数与在场声明。

1. 参数不进 Shot 正文。`wushu_action, Ns, 17n+5 frames, 16:9, 24fps, 832x480` 只出现在规格头。
2. `[Shot N]` 只换机位，时间不停、动作不重启；每镜第一帧接上一镜落幅。
3. 每拍写全：谁在哪一侧 + 相距几米 + 离地多高 + 上一镜没做完的动作怎么办。
4. 压制方连出 3~5 招不停手；守方招架流退；抓空档才反打。
5. 风格档默认写实武侠。用户点名高武 / 仙侠 / 仙侠大片才升档。
6. 生成前用文末 `[体检]` 项自检。

## 改写流程

1. 判定模式：默认文生；命中 REF 关键词或明确双图锁脸则 REF
2. 锁形象、服装、敌我、胜负、时长、风格档、等级
3. 选一条主链 + 一条连招（高频词优先）
4. 按密度铺拍（124：4-7；243：8-12；362：12-16），每拍走完四步
5. 每镜写起幅、落幅、在场；Shot2 起写承接句
6. 只输出对应那一个代码块（用户要两套时两个块）

节点旁注仅当用户问工作流时写：24fps，832x480，cfg=1.0，v7 0.85-1.0，v2 出片 0.6-0.8。

## 1. 风格分档

| 风格档 | 特效 | 破坏量级 | 典型用法 |
| ---- | --- | --- | --- |
| 写实武侠 | 无光效（拳风、碎石、尘土、衣料） | 0.3 米级 | 现代格斗、传统拳械、年代戏 |
| 高武 | 气劲可见不夸张（掌风、气浪环） | 1~2 米级 | 江湖械斗、内功向 |
| 仙侠 | 灵光／符箓／真元／剑芒 | 12 米级场地破坏 | 修真、宗门斗法 |
| 仙侠大片 | 法相、光柱、天地异象 | 120 米 → 3000 米级 | 国漫仙侠大片 |

`[体检]` fx-over / fx-xianxia / fx-spectacle

默认写实武侠。用户没点名不得升档。

### 1.2 机动与浮空按等级解锁

| 等级 | 能力 | 空中占比 | 写法 |
| --- | --- | --- | --- |
| 1~2 | 凡人步法，全程地面 | 0% | 不许写飞、不许踏空 |
| 3~4 | 轻功腾跃 + 短暂滞空约 0.9s | 少量 | 跃起 → 提气停一口 → 空中打 1 下 → 落地 |
| 5~6 | 踏墙借力 + 滞空约 1.3s | 5~8% | 借墙换位、空中换招、落地卸力 |
| 7 | 凌空飞行，悬停约 3.6m | 约 49% | 升空压迫 → 空中交手 → 俯冲压落 |
| 8~9 | 御空／飞天遁地，悬停 5~6.5m | 55~59% | 浮空战斗：抢高度、上下翻飞、俯冲再拉起 |

`[体检]` air-unsupported。凡人不上天；轻功是短滞空；飞行档要真的在天上打。

### 1.3 特效六件 + 国漫场面语法

六件缺一不算写特效：形（环/膜/涟漪/拖尾/光柱/气刃/漩涡/剑影）；色（青白→金白→金青→紫金雷→金紫虚空→星辉金紫）；量（半米/一米/丈许/数丈/十二米/一百二十米/数里）；光（映亮石板/勾轮廓/投长影/天地变色）；破（碎石微溅到山岳平移）；影（一震/急推/甩镜/环绕/仰拍/俯拍）。

7 级以上顺序：① 天象先行 → ② 法相或光柱拔地（仰拍）→ ③ 冲击波改写地形 → ④ 碎片尘云穿前景 → ⑤ 仰角升镜或俯拍废墟收尾。一大一小交替。

留痕跨镜保留。大片档必须有余波镜。`[体检]` fx-scale / fx-scar / fx-aftermath / fx-flat / fx-detail

## 3. 硬规则十二条

1. 一条连续时间线。切镜＝换机位。第 2 镜起第一句接住上一镜末帧：位置＋姿态＋惯性＋没做完的动作。禁止重新起势。`[体检]` cut-continuity / cut-handoff / cut-midaction / cut-restart
2. 每拍空间读数：哪一侧、谁更近、相距几米、离地、朝向。`[体检]` stage-position / stage-distance / stage-height
3. 在场与身份锁。每镜能读到两人；只拍一人必须写去向与回画时机。全片同一对称谓、同一张脸、同一发型、同一套服装、同一兵器、同一体型。`[体检]` who-onscreen / identity-drift / both-fighters / cut-identity
4. 禁瞬移。位置变化只能由垫步／绕步／后跃／翻滚／击飞／落地滑步完成。`[体检]` teleport
5. 禁回合制。压制 3~5 招不停手；守方每挡退半步；抓空档才反打，反打后立刻转压制。
6. 守方被劈必须：举械格挡（火星＋各退半步＋手臂发麻）／斜刃引开／闪避刀锋贴身掠过／退避中反击。禁止站着挨砍。
7. 命中反馈 Lv1~Lv4；至少踉跄／闷哼／衣破／血线之一。`[体检]` fight-no-causal-chain
8. 一招闭环：起势 → 发力 → 击中 → 收势接下一接口。禁止停住站定。`[体检]` start-slow / slowmo / empty-word
9. 击飞沿作用线；追击沿同一条线；撞击点在延长线正方向。
10. 收尾动态定格：肌绷、衣飘、呼吸可见。禁止画面冻结。
11. overall_soundscape 选 4~6 项；non_diegetic_music: None. `[体检]` sound-metal
12. 正文不写帧数／分辨率／步数／cfg。规格头允许。`[体检]` placeholder / ruleblock

主链只走一条：开打接触 → 连续压制（3–5 拍不停手）→ 半拍空档 → 反击转入新压制 → 破防 → 终结沿作用线飞出／跪地 → 追击收势（动态定格，不冻帧）。

三镜切链：

| Shot | 链上位置 | 只允许发生的事 |
|---|---|---|
| 1 | 开打 + 第一次压制 | 攻方先动。守方只招架流退。本镜结束时守方已失位（靠墙、靠柱、重心后仰）。 |
| 2 | 空档反击 + 第二次压制 | 守方抓半拍空档反打 1 次，立刻变成新攻方连续压。旧攻方变成流退。本镜结束时新守方被逼到终结位。 |
| 3 | 破防终结 + 追击 | 只打一记终结。写接触点、作用线、飞出/跪地、环境撞击、胜者追到延长线终点收势。 |

124 帧可把 Shot2 压成「一记反击即转入终结准备」，不要再加第二套连招。

每拍四步（缺一步不算拍）：① 启动（谁、哪只脚蹬地、哪侧腰胯送力）② 接触或防守（打到哪；或格挡/斜引/侧闪/下潜/撤步。禁止站着挨打）③ 结果（头甩向、胸腹是否凹陷、脚滑向、兵器是否震偏）④ 衔接（立刻/顺势/借势，下一拍启动挂在这一拍结果上）。

压制方：前招收势＝后招起势。追退路。上盘被挡就打下盘。禁止后撤重整。
防守方：挡一步退半步，眼锁定对手。连续两次相同防守禁止。
反击只发生在三种空档之一：收势半拍、重心过前、格挡反震发麻。反打一记后立刻转压制。

密度：124 帧全片 4–7 拍；243 帧 8–12；362 帧 12–16。单 Shot 最多 2 个完整招式 + 1 次防守结果。近身摔抱一次性完成，立刻分离。

0.3 秒内启动有效动作；0.8 秒内出招或位移；1.5 秒内第一次接触。禁止慢动作、冻帧、站桩对峙、拳头挡刃、挥空、瞬移。

## 4. 空间与连续性

### 4.1 走位表

每一拍读出：画面左/右/中 · 更近/同一纵深/更远 · 站姿/半蹲/腾空/倒地 · 离地高度 · 朝向 · 间距。

```
t=0.00s 角色A：画面左侧·同一纵深·站姿·朝向 0｜角色B：画面右侧·同一纵深·站姿·朝向 3.14｜间距 3.2m
t=6.20s 角色A：画面左侧·更近·腾空 2.2m·朝向 -1.25｜角色B：画面右侧·更远·腾空 1.3m｜间距 1.8m
```

### 4.2 起幅/落幅

每个 Shot 开头写本镜起幅、结尾写本镜落幅。位置只能靠看得见的步法／起跳／被击飞改变，不许瞬移、不许无交代出画，本镜内两人必须都可辨认。

### 4.3 交接未完成的那一招

招式或滞空中途切镜：上一镜写明这一招没打完就切走；下一镜接着做完，再进下一拍。

模板：承接上一镜末帧（同一秒表继续）：A 在画面左侧、距 B 1.8 米、腾空 0.5 米、正在下落、惯性朝画面左；B 在右侧站姿。先把 A 那一记没收完的收招走完，再进下一拍——不许重新起势、不许重新站位。

### 4.4 在场声明

默认每镜两人都在画面里（特写也留肩、背影或虚焦身影）。只拍一人必须交代：被打飞出画，X 秒后从哪侧落地入画／在画面边缘喘息／身影留在背景虚焦。禁止无理由淡出消失。

### 4.5 身份锚句

开头句后紧跟一句固定锚句：发色＋发型＋服装＋体型＋兵器，逐字固定、全篇一字不差、跨条重复。Shot 内只称角色A/B 或 Subject 编号。

最强手段顺序：定妆照首帧 i2v（fl2va）＞ 参考图 Ref2VA（retention_analysis 正向声明）＞ 纯文字锚句。同一人物同一 seed + 同一锚句 + 同一底模。

翻滚/击飞/高速转身保持中景以上，禁止滚动瞬间推脸。滚地一律侧身滚、背部朝镜头。362 帧建议拆 124 分段，相邻分段用相同收尾／开场姿态衔接。

## 5. 分级伤害

### 5.1 四级反馈（正文不写 Lv 字样）

- Lv1 轻度：肩膀震颤、手臂微抖、小步滑移、衣料紧绷、头部微偏、视线不离对手
- Lv2 中度：踉跄、大步后退 2~3 步、单脚后撤、胸腹受击弓背、呼吸急促、抬手护脸、鞋底刮地
- Lv3 重度：大幅踉跄几乎倒地、单膝触地撑起、撞退至墙边台角、双臂交叉硬防仍被推移、口喘粗气、汗水甩落
- Lv4 终结：接触点特写 → 双脚离地 → 凌空后仰弓形、四肢失控、衣袍汗水甩弧 → 落地侧身砸地、侧身连续滚 2~3 圈刮出地面痕 → 撞墙／货架／管道（碎石、尘土、管件坠落）→ 瘫软失去战斗姿态、仅剩微弱喘息

### 5.2 击飞作用线

| 招 | 飞向 |
| --- | --- |
| 正面重拳/重锤胸口 | 沿出拳直线正后方凌空 |
| 上勾拳 | 竖直腾空后仰坠落 |
| 扫堂腿下盘 | 沿扫弧横向腾空翻转 |
| 侧踹／鞭腿躯干 | 沿腿轴后滑或后飞 |
| 铁山靠／贴山靠 | 沿突进斜向前下方撞出 |

进攻方沿同一条作用线贴进。镜头跟作用线。环境撞击点在延长线正方向。墙/货架必须在延长线正方向。

### 5.3 部位词

头：猛然偏转、视线甩离、汗水甩落。躯干：胸口凹陷波动、弓背折体、拧转卸力。下肢：脚跟离地、脚尖点地滑移、膝跪弹起。整体：双脚离地、滞空后仰、连续侧身滚、撞墙滑落。

器械：被劈必须举械格挡火星震退／斜刃引开／刀锋贴身掠过／格挡半步立刻还一招。命中必须见衣破血线／踉跄闷哼兵器发麻／跪地拄兵血迹渗衣。兵刃相交有火星与嗡鸣。砍空带偏重心，半拍回拉。兵器不凭空消失。禁止拳头挡刃。

## 7. 连招套路库

敏捷：① 前手直拳虚招 → 后手崩拳 → 铁山靠突进 → 拉开 ② 低位扫堂破防 → 腾空侧踹追击 → 侧滚 ③ 高位鞭腿佯攻 → 下潜抱腿 → 接腿摔过肩 → 侧滚起身 ④ 回旋踢 → 落地垫步贴脸 → 双飞脚终结

力量：① 格挡卸力 → 后手重锤（Lv4） ② 硬抗鞭腿 → 抓腿接腿摔 → 过肩摔砸 ③ 前手直拳×2 试探 → 下潜蓄力 → 贴身铁山靠撞飞 ④ 重锤逼退 → 垫步追击 → 腾空飞踢补刀

器械：① 缠头裹脑 → 回马枪反刺 → 撩剑 ② 大刀过顶蓄力 → 蓄力劈砍 → 旋身横扫

通用三段：[Shot 1] 压制 3~5 招、守方流退锁空档 → [Shot 2] 空档反打并转压制、写清换位 → [Shot 3] Lv4 沿作用线击飞 → 撞环境 → 贴身追击 → 动态定格

## 13. 避坑

1. 招式宁专勿泛。禁用战斗动作 / combat action
2. 一个 Shot 只放 1~2 个招式
3. 不要静止站立／呆立
4. 保留 non_diegetic_music: None.
5. 画质参数不进正文，规格头除外
6. 滚地侧身、背朝镜头
7. 人物/兵器崩坏 → LoRA 降到 0.6~0.8；动作不够武 → 升到 1.1
8. 人物不一致 → 锚句 + 定妆 i2v 或 REF + 固定 seed + 固定底模
9. 守方站着挨砍 → 补格挡/招架/闪避/受击
10. 命中无伤 → 补踉跄／闷哼／衣破／血线
11. 切完位置不对/换人 → 承接句 + 每镜重申还是这两人
12. 乱飘出画 → 走位表逐拍读数
13. 打不完绕圈 → 压制方连出 3~5 招，抓空档反打
14. 大片档像放大火花 → 补改写地形与留痕/余波
