# H3 宫斗商品短剧 h3-gongdou-product-drama-v2 v1.2.0

把商品卖点改编成 9:16 竖屏后宫权谋短剧：商品靠"争宠、献礼、验货、反转、晋位"改变局势，而不是被举着念广告词。全片先锁角色、场景与商品，再写分镜，避免多段参考生视频时人物走样。

## 交付物

一次性给齐七件：

1. 一句话创意
2. 角色一致性表 + 场景锁定表 + 英文锚点块
3. 角色卡与场景卡生成提示词（默认 Qwen-Image；角色卡 16:9 三视图，场景卡 9:16）
4. 全局素材参考顺序表（按实际素材连续编号 + 每镜挂载顺序，无空位）
5. 30–45 秒完整脚本
6. 逐秒分镜表（含每镜素材挂载）
7. 每镜 MiniMax H3 提示词（挂卡/图走 Ref2VA 六段式，确无参考图走 T2VA 三字段）+ 全片统一音画与抗漂移设定

## 全片预算

| 项         | 上限                                                      |
| ---------- | --------------------------------------------------------- |
| 主要角色   | 4 人（群演总数不限，不建卡；单镜入画按景别控制）          |
| 场景       | 3 个（默认 1 个主场景，每场景一张卡）                     |
| 商品参考位 | 最多 2 个：主图（有图则必用）、细节（可选，无图不占编号） |

超限处理：合并功能位、次要角色降为群演、场外空间改台词交代，不悄悄超编。

## 安装

把整个 `h3-gongdou-product-drama-v2` 目录放进你所用的 Agent 客户端 skills 目录，重启会话生效：

- Qoder：`~/.qoder/skills/`
- Claude Code：`~/.claude/skills/`
- 通用 Agent Skills：`~/.agents/skills/`

Windows 对应 `%USERPROFILE%\.qoder\skills\`、`%USERPROFILE%\.claude\skills\`、`%USERPROFILE%\.agents\skills\`。

安装后的层级应为 `.../skills/h3-gongdou-product-drama-v2/SKILL.md`，不要多套一层同名目录。

## 怎么用

一句话即可触发：

> 用宫斗商品短剧，把这款 <商品名> 做成 40 秒竖屏短剧，卖点是 A / B / C，用 MiniMax H3 生成，投抖音。
> 附产品图。

也可以只给产品图，技能会从可观察特征反推卖点，并标注哪些是推断。

## 使用顺序

1. 先出角色卡、场景卡提示词，把卡图生成出来（或先留 `pending`）。
2. 检查全局素材参考顺序表：按实际素材连续编号（商品 → 角色 → 场景），中间无空号，编号全片不改。
3. 再按分镜的"素材挂载"列逐镜生成 H3 提示词；每镜附件顺序为 商品 → 在屏角色卡 → 场景卡。
4. 同一场景逐字复用场景卡句，同一角色逐字复用英文锚点句。

## 三条底线

- 不虚构成分、功效、价格、销量、认证；只写看得见的。商品细节图没有就不占编号，不编造视角。
- 人物与场景全场锁定：角色卡、场景卡是唯一事实源，提示词逐字引用，不逐镜重新发明。
- H3 每条提示词只生成一个 2–8 秒镜头（确需一镜内剪切时最多两段），绝不把整份脚本塞进一条 prompt。

## 适配

- 竖屏 9:16，抖音 / 小红书 / 视频号信息流
- 提示词默认按 MiniMax H3 规范写：英文正文 + `<d>[Chinese]` 中文台词；有卡/图走 Ref2VA，无卡才 T2VA
- H3 没有负向字段，原负向词全部改写为正向锁定句（见 `references/02-prompt-recipes.md` 第 9 节）
- 投 Seedance 2.5 / 可灵 / 即梦需按 02 第 11 节转换；Midjourney 只用于角色定妆图与商品氛围图
