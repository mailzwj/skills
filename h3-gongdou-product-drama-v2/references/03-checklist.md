# 交付前质检清单

逐条打勾，任何一条不过就返工，不交付"差不多"的版本。

## A. 结构与节奏

- [ ] 3 秒内出现明确冲突或身份压制（一句狠话 + 一个动作，不是旁白铺垫）
- [ ] 商品首次出现不晚于第 8 秒
- [ ] 商品真正改变了剧情走向，而不是被人举着说了几句好话
- [ ] 每 5–8 秒有一次信息或权力关系推进，无过渡性空镜
- [ ] 有且至少有一次有效反转，反转的胜负手落在商品卖点上
- [ ] 结尾同时包含：记忆点台词 + 商品名 + 利益点 + 单一行动指令
- [ ] 全片时长在目标区间（默认 30–45 秒），无超时段落

## B. 卖点

- [ ] 核心卖点只保留 1–3 个
- [ ] 每个卖点都有动作、结果或视觉证据，不是只靠台词说
- [ ] 一个镜头只承担一个主卖点
- [ ] 卖点全部可验证，没有成分、功效、价格、销量、认证的凭空捏造
- [ ] 没有"第一、顶级、百分百、治疗、永久、国家级"等绝对化或违规表达

## C. 人物、场景与连续性

- [ ] 主要角色 2–4 人，没有工具人凑数
- [ ] 群演不计入上限，总数不限，但不进角色表、不建卡、不建 Subject、不给特写、不承担台词；单镜入画按景别控制并写明人数
- [ ] 场景 1–3 个（默认 1 个），每镜都能对应到某张场景卡，没有临时新增空间
- [ ] 每个角色写清年龄段、脸型、发型、服装主色、标志配饰、站位、说话节奏
- [ ] 每个角色有 3–4 个跨镜头复述的身份锚点
- [ ] 第二步产出的英文锚点块齐全，与中文角色表、场景锁定表一致
- [ ] 提示词中英文锚点逐字复制，没有换同义词
- [ ] 无剧情原因的换装/换发型/换道具已清除
- [ ] 同框人物左右站位在所有镜头里保持一致，门/窗方位不跳
- [ ] 主位与新人不同色系，同框可分辨

## D. 商品

- [ ] 包装、Logo、颜色、形状、关键结构跨镜头一致
- [ ] 商品参考位最多两个：主图有图则必用；细节有则编号挂载、无则不占编号，也不描述看不见的视角
- [ ] 有商品主图时，每个含商品镜头挂主图并写 fully_preserved；无商品图时用英文商品句全文锁定并标注待补图，不假装有图
- [ ] 商品镜 retention_analysis 为 fully_preserved，并写明形状、颜色、标签位置、零件数与参考图一致
- [ ] 标签按"空白白色标签"处理，品牌名与小字走后期，提示词里不生成伪文字
- [ ] 商品高光、标签位置在分镜与提示词里描述一致
- [ ] 食品写成"馅料不溢出、断面完整"；护肤保持梳妆/日常环境；服装按版型垂坠

## E. 卡与素材参考

- [ ] 每个主要角色一份角色卡提示词（16:9 横版），含身份锁句、三视图、表情条、细节特写、图内标注、卡图风格锁、负向
- [ ] 每个场景一份场景卡提示词（9:16 竖版），无人、无商品、无剪影，含固定地标屏幕位置与光位基线
- [ ] 卡提示词自洽可粘贴，不依赖上下文；卡图未生成时状态标 pending
- [ ] 全局素材参考顺序表齐全，含顺序、Subject ID、类型、卡名、参考图、状态、出现镜头
- [ ] 表内只列实际素材，按数量连续编号 1 到 N，没有 `empty` 占位行或中间空号
- [ ] 建表顺序为 商品主图 → 商品细节（有才编）→ 角色卡 → 场景卡；定稿后新增素材追加表末，已有编号未重排
- [ ] 分镜清单"素材挂载"列与顺序表"出现镜头"列一致
- [ ] `<Subject N>` 全片稳定、跨镜复用；`<Picture N>` 按本条挂载顺序从 1 起
- [ ] 附件挂载顺序为 商品 → 在屏角色卡 → 场景卡；超限时未静默丢商品主图或在屏主位卡

## F. 分镜与提示词

- [ ] 单镜 2–8 秒：常规镜 4–8 秒，短切镜 2–3 秒，全片短切不超过 3 个
- [ ] 全片 6–10 镜（30–45 秒）；15 秒版 3 镜，或 3 镜 + 1 个短切
- [ ] 每条提示词符合所选 H3 模式：有卡/图 → Ref2VA 六段齐全；确无参考图 → T2VA 三字段齐全
- [ ] 每条提示词自洽：subject_definitions 在本条内定义，没有引用上一条的定义
- [ ] `<Subject N>` 按全局顺序表编号；群演和纯文字角色不建 Subject，用英文锚点句 + `(Sx)`
- [ ] 风格句逐字复制风格锁英文串；同场景逐字复用场景卡句，同角色逐字复用角色锚点句
- [ ] 角色镜写明与角色卡一致；场景镜写明与场景卡一致；商品镜写明与商品图一致
- [ ] 台词写在 `<d>[Chinese] …</d>` 内且为原文；旁白用 `says in an off-screen voiceover` 并注明嘴唇闭合
- [ ] 说话人编号按本条发声顺序，跨镜编号可不同
- [ ] 运镜写成"类型 + 幅度 + 速度"的自然句，每个镜头只有一个主动作
- [ ] 每镜开头有承接上一镜的起始状态，未引用不存在的标签
- [ ] `overall_soundscape` 只写环境/动作/非语言人声；`non_diegetic_music` 只写器乐/速度/节奏/动态
- [ ] 商品镜 `detailed_description` 写明参考图在哪一刻生效（如 `matching <Picture 1>`）
- [ ] 没有负向字段；原负向意图已改写成正向锁定句
- [ ] 未把整份脚本作为单条 prompt

## G. 文案

- [ ] 台词短、能截成弹幕，一句里最多一个称谓
- [ ] 台词原文写入 `<d>`，未翻译、未改写；一句只承担一个意思
- [ ] 台词长度与镜长匹配（4–6 秒镜 ≤20–25 字，2–3 秒短切 ≤8 字）
- [ ] 无大段仿古文，现代观众一遍能听懂
- [ ] 未照搬知名宫斗剧的台词、角色名、标志性服化道
- [ ] 广告信息通过剧情机制传递，结尾没有突然硬插广告词
- [ ] 台词与镜头动作对得上（说到"听这一声"时确实有声音动作）

## H. 合规

- [ ] 无贬损、无虚构竞品事实；对比只用尺寸、材质、体验、便捷、口感、质感等可验证差异
- [ ] 未出现竞品品牌名、未做伪造参数
- [ ] 医疗、金融类商品未承诺疗效或收益
- [ ] 生成真人角色时使用方式符合投放平台的 AI 内容标注要求

## 返工优先级

若时间只够修三处，按此顺序：**商品是否改变剧情 > 卖点是否可视化 > 结尾是否带品牌名与行动指令**。
