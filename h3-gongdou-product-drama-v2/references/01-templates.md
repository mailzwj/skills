## 0. 阵容与场景预算

写模板前先定预算：主要角色 ≤4 人、场景 ≤3 个、商品参考位固定 2 个。群演总数不限，但不建卡、不建 Subject、不给特写、不承担台词；单镜入画按景别控制。

| 模板       | 主要角色                             | 场景                   | 商品参考位              |
| ---------- | ------------------------------------ | ---------------------- | ----------------------- |
| A 献礼逆袭 | 3–4（主位 / 新人 / 争宠者 / 递物者） | 1（内殿正堂）          | 主图 + 细节             |
| B 御前验货 | 2–3（主位 / 献礼者 / 质疑者）        | 1（御前长案）          | 主图 + 细节（结构）     |
| C 争宠擂台 | 3（主位 / 两位嫔妃）                 | 1（正堂或偏殿）        | 主图 + 细节（同项对比） |
| D 危机救场 | 2–3（主位 / 小人物 / 质疑者）        | 1–2（出事处 + 处置处） | 主图（细节可选）        |

超预算时按顺序砍：合并功能位 → 群演化 → 场外空间改台词交代。不得为了排场新增角色卡或场景卡。

## 1. 四个宫斗机制

| 机制     | 权力动作                    | 最适合的商品类型                                        | 需要的对手                           |
| -------- | --------------------------- | ------------------------------------------------------- | ------------------------------------ |
| 献礼逆袭 | 被轻视 → 献上 → 验证 → 晋位 | 有明确"上一代/旧方案"的品类，如清洁、收纳、护肤、小家电 | 一件被嫌弃的旧物 或 一位压人的竞争者 |
| 御前验货 | 审 → 查 → 比 → 判           | 质感和结构能被看清的品类，如面料、器皿、五金、食品原料  | 一位公开质疑者                       |
| 争宠擂台 | 两方同台，各显一手          | 有可验证差异的品类，如尺寸、便携、口感、质感            | 同品类另一种方案（不得贬损）         |
| 危机救场 | 场面失控 → 一件东西稳住     | 解决突发尴尬的品类，如除味、去渍、应急、补妆            | 一个具体事故，不需要人当反派         |

选机制的唯一标准：**商品最能被"看见"的那个动作**，落在哪种权力关系里最自然，就选哪个。

## 2. 模板 A：献礼逆袭（45 秒标准版）

| 段落 | 时间   | 剧情动作                         | 权力关系           | 商品                          |
| ---- | ------ | -------------------------------- | ------------------ | ----------------------------- |
| 压制 | 0–3s   | 旧物被掷回案上，或旧方案当众出丑 | 主位压新人         | 不出现                        |
| 献礼 | 3–10s  | 新人上前，双手承托，打开         | 新人争取一次机会   | 第 6–8 秒必须入画             |
| 试用 | 10–22s | 三个动作，每个动作一个卖点       | 观众在场，权力暂悬 | 三个镜头，三个卖点            |
| 挑刺 | 22–30s | 争宠嫔妃抢话、质疑、上手翻查     | 反击压力最大       | 商品被翻看，仍站得住          |
| 反杀 | 30–36s | 一个可见结果打脸质疑             | 权力倒向新人       | 结果由商品直接产生            |
| 晋位 | 36–41s | 主位一句赐名/下令                | 商品获得制度性认可 | 商品被端走/入册               |
| 落款 | 41–45s | 微距特写 + 字幕                  | 打破第四面墙       | 商品 + 品牌名 + 利益点 + 指令 |

**卖点分配示例（三卖点 → 三动作）**

- 卖点 1（结构/材质）→ 手指划过、按压、弯折、提起
- 卖点 2（使用结果）→ 一次见效的可见前后对比
- 卖点 3（便捷/尺寸）→ 单手完成、收进袖中、放下不占地

## 3. 模板 B：御前验货（45 秒标准版）

| 段落     | 时间   | 剧情动作                 | 台词密度 | 商品               |
| -------- | ------ | ------------------------ | -------- | ------------------ |
| 立威     | 0–3s   | "若不好用，拖出去。"     | 极简     | 不出现             |
| 呈上     | 3–8s   | 托盘/匣子递到御前        | 一句     | 首次可见，正面     |
| 查验     | 8–15s  | 外观、材质、结构逐项看   | 短问短答 | 顶视/侧面微距      |
| 现场对比 | 15–28s | 旧方案 vs 本商品，逐项过 | 中间密   | 同框对比           |
| 反转     | 28–36s | 质疑者上手亲试，无话可说 | 一句     | 结果落在手里       |
| 赐名     | 36–41s | "传下去，全宫照此办。"   | 一句     | 商品被合上/收起    |
| 落款     | 41–45s | 特写 + 字幕              | —        | 商品 + 品牌 + 指令 |

**关键技巧**：验货段落用"问一句、动一下、看一眼"的三拍节奏，别让任何人连续说两句话。

## 4. 模板 C：争宠擂台（40 秒双品对比）

| 段落     | 时间   | 动作                       | 注意                                 |
| -------- | ------ | -------------------------- | ------------------------------------ |
| 开擂     | 0–3s   | 两位嫔妃各执一件，主位居中 | 两人的衣服颜色必须能一眼分开         |
| 各表     | 3–12s  | 各自展示一个差异点         | 只陈述自己的特征，不评价对方         |
| 同项对决 | 12–24s | 同一动作、同一角度各做一次 | 机位一致，才有说服力                 |
| 判定     | 24–32s | 主位用一个可验证标准裁决   | 标准必须客观：容量、重量、耗时、手感 |
| 收服     | 32–36s | 落败方认可/求同款          | 不允许嘲讽                           |
| 落款     | 36–40s | 商品特写 + 字幕            | 品牌 + 利益点 + 指令                 |

**合规红线**：不出现竞品品牌名、不出现"劣质/假货/踩雷"类贬损，不做伪造参数。落败方输在"更符合本宫这一处需要"，而不是"东西差"。

## 5. 模板 D：危机救场（30 秒短版）

| 段落   | 时间   | 动作                                           |
| ------ | ------ | ---------------------------------------------- |
| 出事   | 0–3s   | 场面崩：茶水泼了、衣料沾了、气味传开，主位皱眉 |
| 众人退 | 3–6s   | 无人敢动，责任压向最边缘的人                   |
| 出手   | 6–14s  | 小人物拿出商品，两个动作解决                   |
| 反转   | 14–22s | 摆平，主位意外抬眼；质疑者无话                 |
| 赏     | 22–27s | 一句封赏/调岗/留用                             |
| 落款   | 27–30s | 商品特写 + 字幕                                |

短版只能带 1–2 个卖点。别贪。

## 6. 台词库

### 开场压制（0–3 秒用，每句不超过 12 字）

- "这也能入眼？"
- "抬回去。本宫不收废礼。"
- "凭你，也配站在这儿？"
- "用过的东西，也敢往本宫跟前递。"
- "三个时辰，办不成，你就别回来了。"
- "若不好用，拖出去。"

### 献礼与争取

- "娘娘容我说一句。"
- "给我一炷香，不合心意，我自领罚。"
- "旁的不敢说，这一件，我用过。"

### 展示体验（卖点句，必须短且具体）

- "您听这一声。"（结构/材质）
- "一只手，就够。"（便捷）
- "从这里到这儿，一点没剩。"（清洁/用量）
- "同一样东西，这个轻了一半。"（重量）
- "晾一炷香，摸上去就是干的。"（速干）
- "不靠香遮，是味道真的没了。"（除味）

### 挑刺与反击

- "看着倒是花哨。"
- "这几日新鲜，过了几日呢？"
- "说得这样好，敢当场试？"
- "回娘娘，靠的不是花言巧语，是这一用便知。"
- "您再翻一遍，还是这样。"
- "我不解释，您看结果。"

### 判定与晋位

- "本宫倒要看看，它凭什么得宠。"
- "传下去，今日起，它便是宫里的常备。"
- "这一格，给它留着。"
- "别人争的是恩宠，它争的是回购。"
- "往后这宫里，都按这个来。"

### 落款（品牌名 + 利益点 + 行动指令）

- "<商品名>，<一句话利益点>。宫里都在用的，下方自取。"
- "<商品名>｜<核心卖点短语>。点左下，今日上新。"
- "<商品名>，<使用场景>就靠它。橱窗已备好。"

> 落款句必须出现商品名，且行动指令只有一个（点下方/进橱窗/评论区留"1"），不要三个指令并列。

## 7. 晋位/赐名命名法

用"赐名"作为商品名记忆点，但**不改商品真名**，只加一个宫里的封号，形成"封号 + 真名"结构：

| 商品品类  | 可用封号方向 | 落款写法示例                |
| --------- | ------------ | --------------------------- |
| 清洁/去污 | 净、拭、洁   | "赐名'一拭'——<品牌/商品名>" |
| 香氛/除味 | 静、息、安   | "赐名'安息'——<品牌/商品名>" |
| 护肤/润养 | 润、凝、素   | "赐名'素润'——<品牌/商品名>" |
| 收纳/器物 | 藏、纳、匣   | "赐名'一纳'——<品牌/商品名>" |
| 食品/茶饮 | 甘、醇、暖   | "赐名'一盏'——<品牌/商品名>" |
| 服饰/面料 | 轻、软、素   | "赐名'贴身'——<品牌/商品名>" |

封号只能用一次，同一品牌系列可复用同一封号形成资产；不要每支片子换一个封号。
