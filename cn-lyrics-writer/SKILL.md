# 中文歌词创作（五维创作法）

创作中文歌词时遵循本技能。核心信念：**歌词是"能够被歌唱的诗歌"**——既要文学性（立意深、意象美、语言精），也要音乐性（押韵顺、节奏稳、可传唱）。本技能把大师经验内化为可操作的创作准则，而非模仿某个人的风格。

## 创作总流程

1. **收集需求**：根据用户给出的信息补全缺失维度（见下）。信息不足时先问，不要臆造用户未指定的关键约束（如曲风、情绪、人称）。
2. **五维设计**：落笔前先在脑中完成五维设计——立意一句话、核心意象、韵辙选择、段落结构。
3. **落笔成词**：按"主歌叙事→副歌爆发"的原则逐段写。
4. **五维自查**：对照本技能的自查清单逐项检查，不合格就修改，直到全部通过。

## 第一步：收集需求（补全五维输入）

创作前确认以下信息，用户已给的直接用，没给的按需追问（最多追问一次，重要约束必须问，其余可合理默认）：

| 输入维度  | 关键问题                   | 默认倾向                   |
| --------- | -------------------------- | -------------------------- |
| 主题/立意 | 这首歌在说什么？           | 用户提供；缺失则追问       |
| 情绪基调  | 甜/悲/燃/释然/治愈？       | 用户提供；缺失则追问       |
| 曲风      | 古风/流行/民谣/R&B/国风？  | 现代流行                   |
| 人称视角  | 我/你/他（她）/物          | 第一人称"我"               |
| 篇幅/结构 | 主副歌循环？是否要桥段？   | 主歌2+副歌2+桥段1+副歌1    |
| 韵辙偏好  | 用户指定或由情绪推断       | 按情绪基调选辙（见十三辙） |
| 特殊要求  | 金句句数、禁用词、命题点题 | 无                         |

若用户信息完整，直接进入设计，不要多问。

## 第二步：五维创作法（核心方法论）

五维 = 立意、意象、语言、韵律、结构。五维相互牵制：立意决定意象方向，意象决定语言取材，语言受韵律约束，韵律配合结构起伏，结构服务立意表达。

### 维1 立意（这首歌的灵魂）

- 用一句话概括主题与态度（≤20字），创作时始终不偏离它。
- 三层次：表层（事件）→ 中层（母题）→ 深层（哲思）。好词由表层自然通向深层，拒绝情绪标签堆砌（"无尽的悲伤、破碎的心房"这类空洞表达禁用）。
- 视角：第一人称代入感强（默认）；第二人称对话感强（情歌）；第三人称适合叙事。

### 维2 意象（画面感）

- 公式：意象 = 物象 + 情感。把抽象情绪（思念、孤独、遗憾）翻译成具体物象（窗外的雨、空荡的房间、末班车）。
- 画面三要素：时间（傍晚/那年）、地点（站台/天台）、动作（奔跑/回头）——每一句都应是可拍摄的镜头。
- 五法：借景抒情、以物拟人、通感（打通感官）、意象对比（反差强化）、意象贯穿（全歌围绕一个核心意象深化）。
- 追求陌生化搭配，拒绝滥俗意象（月亮代表我的心式的直白比喻）。

### 维3 语言（炼词造句）

- 四要求：易懂、动听、有文采、有辨识度。介于口语与书面语之间。
- 多用具体名词+动词，少用抽象形容词；句子短，便于换气；首句要抓人。
- 修辞服务情感：比喻、拟人、排比（气势）、设问反问（冲击）、对比（反差）、反复（记忆钩子）、通感。
- 全歌语言风格统一（古风词不掺现代网络语；现代流行词不强行文言）。
- 避免套话：眼泪/心碎/永远爱你/天长地久 等陈词需替换为具体表达。

### 维4 韵律（声律节奏）

- 押韵遵循**十三辙**（现代歌词可用同辙宽韵、近似韵）：
  发花辙(a/ia/ua 明亮)、梭波辙(o/e/uo 温和)、乜斜辙(ie/üe 感伤)、姑苏辙(u 低沉)、一七辙(i/ü 轻快)、怀来辙(ai/uai 舒展)、灰堆辙(ei/ui 含蓄)、遥条辙(ao/iao 昂扬)、由求辙(ou/iu 惆怅)、言前辙(an 悠长)、人辰辙(en/in 柔和)、江阳辙(ang 豪迈)、中东辙(eng/ing/ong 浑厚)。
- 副歌用韵应比主歌更响亮；韵脚落在句尾重音，一般每句或隔句押韵。
- 句尾字声调与旋律配合（旋律上行配阳平/上声，下行配阴平/去声），避免"倒字"（唱出来变义）。
- 字数随旋律疏密变化；主歌可长句口语化，副歌宜短句有力；排比制造节奏记忆点。

### 维5 结构（章法布局）

- 单位：主歌（叙事铺垫）→ 导歌（情绪爬升，可选）→ 副歌（主题爆发）→ 桥段（转折升华，可选）→ 尾声（收束）。
- 黄金结构：A B A B C B。副歌承载最核心的句子并重复形成记忆点；主歌"提出问题"，桥段"回答问题"（新视角或情绪升级）。
- 情绪阶梯式上升，副歌信息密度高于主歌；首尾呼应形成闭环。
- 默认结构：主歌1 → 主歌2 → 副歌 → 主歌3（可选）→ 副歌 → 桥段 → 副歌。

## 第三步：大师方法论融合（内化为创作准则）

创作时把以下大师经验当作"技法库"自然调用，不绑定具体风格：

### 方文山（意象与考据）

- **意象考据**：为核心意象做功课——青花瓷的釉色、江南的烟雨、天青色的典故，让意象有文化纵深。
- **画面如电影分镜**：一句一个镜头，有时间、地点、动作。
- **炼字**：动词要精确（"釉色渲染仕女图"的"渲染"）。
- **服务性创作**：歌词是为旋律和听众服务的，追求情感最大公约数——寻找能打动最多人的普世情感。

### 林夕（隐喻与留白）

- **深情隐喻**：把感情藏进日常事物（《富士山下》的雪山、《红豆》的红豆），不直说而让人回味。
- **留白**：点到即止，把余味留给听众；情绪推进有层次（平淡→伤心→看透）。
- **金句提炼**：一句话写尽一种人生况味（"但凡未得到，但凡是过去，总是最登对"）。

### 黄伟文（态度与叙事）

- **态度鲜明**：敢于写狠、写直白，情绪不模糊（励志靠黄伟文——他的词有决绝的力量）。
- **叙事完整**：用一件事讲透一个道理（《喜帖街》用拆迁讲放下）。
- **反套路**：用陌生角度写熟悉主题，制造惊喜感。

### 姚若龙（温暖与共鸣）

- **小处见大**：从生活细节入手（"我能想到最浪漫的事，就是和你一起慢慢变老"），日常场景承载深厚情感。
- **温暖治愈**：适合励志、亲情、友情、成长类主题；语言平实却动人。
- **共鸣优先**：写普通人能对号入座的情境。

### 李宗盛（口语与人生）

- **口语化叙事**：像说话一样写词（"你我皆凡人，生在人世间"），贴近真实人生。
- **时间感与回望**：善于写中年回望、岁月沉淀（《山丘》"越过山丘，才发现无人等候"）。
- **直击人心**：金句要像老朋友聊天时的一句真话，朴素但有穿透力。

### 融合要点：金句的诞生

**每首歌至少包含 1~2 句金句**（用户明确要求的硬性标准）。金句是"脱离旋律仍能独立流传的句子"，特征：

- 表达一种普世情绪或人生感悟，人人有共鸣；
- 语言凝练，可脱离上下文独立理解；
- 位置：副歌首句或副歌尾句（记忆点最强处）。
- 金句技巧：① 化抽象为具体（"越过山丘"）；② 反常识表达（"得不到的永远在骚动"）；③ 对话式叩问（"为什么你背着我爱别人"）；④ 场景定格（"天青色等烟雨，而我在等你"）。

## 第四步：输出格式

用户选择"仅歌词正文"时，按以下格式输出（干净、可直接使用）：

【歌名】（如有合适歌名可自行拟定，无则省略）
【情绪基调/曲风】一行简要标注（可选，用户要求简洁时省略）

[Verse1]
……（4行左右）
[Verse2]
……
[Chorus]
……（重复）
[Bridge]
……
[Chorus]
……

- 段落之间空行；每行自然断句，符合旋律呼吸。
- 除非用户要求，不输出创作解析、注释或说明。
- 用户要求"分析/解析"时，可额外附五维解析，但歌词正文始终在前。

## 第五步：五维自查清单（成稿必须全部通过）

1. **立意**：一句话能说清这首歌在说什么、什么态度？（说不清 → 重写）
2. **意象**：每句是否可"看到"画面？有无抽象大词空转？（有 → 换成物象）
3. **语言**：逐句朗读是否顺口？有无套话？风格是否统一？（不顺 → 改）
4. **韵律**：韵脚是否响在句尾？有无倒字？字数与旋律断句吻合？（不吻合 → 调整）
5. **结构**：副歌是否承载记忆点？情绪是否逐段升级？首尾是否呼应？
6. **金句**：全歌是否至少 1~2 句可独立流传的金句？（无 → 重炼副歌）
