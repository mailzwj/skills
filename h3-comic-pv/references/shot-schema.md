# 分镜与提示词字段规范

> Created by 迪威

## 分镜表

每个镜头使用以下字段，缺失字段写“无”或“待确认”：

| 字段 | 内容 |
|---|---|
| shot_id | `S01`、`S02` 等，按播放顺序递增 |
| start / end | 时间码，使用 `MM:SS.mmm` |
| duration | 秒数，保留 0.1 秒或更高精度 |
| purpose | 该镜头的叙事目的 |
| visual | 主体、环境、构图、材质、光线、颜色 |
| action | 主体动作和可观察的状态变化 |
| camera | 景别、运动类型、幅度、速度、切点 |
| image_prompt | 可直接交给 ImageGen 的提示词 |
| h3_mode | T2VA / I2VA / FL2VA / L2VA / Ref2VA |
| h3_prompt | 可直接交给 H3 的完整提示词 |
| voiceover | 原文、说话人、语速和停顿 |
| subtitles | 文本、时间、断句和位置 |
| sfx | 环境声、动作声和转场声 |
| music | 音乐层、节拍、进入、退出和音量 |
| continuity | 需要跨镜头保持的内容 |
| negative | 必须避免的内容 |

## 时间线规则

- `S01` 从 `00:00.000` 开始；后续镜头的切点必须严格递增。
- 所有镜头的 `duration` 相加必须等于目标时长，允许的误差不超过 0.01 秒。
- 旁白、字幕和声音效果都要写入时间范围，不用“中段”“结尾附近”等模糊表达。
- 一条旁白跨越镜头时，明确写“跨切点连续”，并在前后镜头保持相同说话人 ID。
- 如果 H3 片段需要拼接，分别写清片段时长、拼接点和衔接方式。

## ImageGen 提示词检查项

每条图片提示词至少包含：

1. 主体和主体数量。
2. 场景、时代、地点和空间关系。
3. 构图、景别、视角和主体位置。
4. 材质、光线、色彩和风格。
5. 必须保留的身份、道具、服装或文字。
6. 负面约束：变形、错字、闪烁、重复主体等。

## H3 提示词检查项

H3 提示词必须遵守 `$h3-prompt-writing` 的对应格式：

- T2VA 使用完整音画时间线。
- I2VA 明确首帧在 `0.00` 秒被完整引用，并从首帧向前发展。
- FL2VA 明确首帧、尾帧和两者之间的连续运动路径。
- L2VA 明确目标尾帧的时间点，并让动作逐步落到尾帧。
- Ref2VA 先定义稳定的 `<Subject N>`、`<Picture N>`、`<Video N>` 和 `<Audio N>`，再说明它们如何保留或参考。
- 基础模式使用 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music`。
- 多参考模式使用六段式全参考结构。
- 所有对话和画面文字保留用户原文；镜头、动作、声音和连续性写清楚。
