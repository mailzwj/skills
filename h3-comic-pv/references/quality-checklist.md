# H3 视频包装交付检查表

> Created by 迪威

## 内容

- [ ] `h3-prompt-writing` 已安装并通过文件完整性检查。
- [ ] 主题、受众、核心信息和片尾结论明确。
- [ ] 每个镜头都有叙事目的，不是纯粹堆画面。
- [ ] 旁白稿没有漏句、错别字或未经确认的事实。
- [ ] 视觉风格规则已经从形容词转成可执行描述。

## 非叙事 PV／片头包装（使用 `motion-package` 时）

- [ ] 前 1–2 秒已经清楚建立角色或产品识别。
- [ ] 节奏有“识别 → 动作／版式升级 → 标题定格”的三段变化。
- [ ] 跳跃、落地、转头、挥手、眼神或产品转面等动作峰值被用作切点。
- [ ] 主色、字版和几何母题在全片保持统一，只允许有意设计的强调色变化。
- [ ] 片尾保留 0.5–1.5 秒让标题、Logo 或英雄姿态可读、可记忆。
- [ ] 音乐、动作音和转场音分层，主要击打点有明确时间位置。
- [ ] 没有把样片中的角色、Logo、标题或版权音乐直接复制到新项目。

## PV 交互流程

- [ ] 用户的一两句话创意已经被整理成 3 个风格选项，并包含最后的“其他／自定义”。
- [ ] 已等待用户明确选择风格；未选择时没有进入角色图、ImageGen、H3 提示词或视频生成。
- [ ] 已记录用户选择的风格，以及自定义文字、图片或视频参考的职责。
- [ ] 已提供或生成角色基准图；没有角色图时没有直接跳到 H3 动作生成。
- [ ] H3 提示词在同一轮中写明音乐、动作音、转场音和环境底噪。
- [ ] 用户明确要求生成，或已确认授权、上传范围和费用后，才提交 H3。
- [ ] 生成后有“保留／修改／重做”反馈节点；修改时只改相关提示词段落。

## H3

- [ ] H3 模式和实际参考素材匹配。
- [ ] 首帧、尾帧和多参考素材的角色没有混淆。
- [ ] 时间点严格递增，镜头总时长正确。
- [ ] 提示词包含动作、镜头、环境声和音乐字段。
- [ ] 参考标签在各段落中含义一致。

## 连续性

- [ ] 人物的脸、服装、年龄、姿势和说话人 ID 连续。
- [ ] 道具、建筑、地图方向和光线不会无故改变。
- [ ] 镜头运动不会突然跳轴或反向。
- [ ] 片段拼接处没有明显的构图、音量或节奏断裂。

## 声音与字幕

- [ ] 旁白、字幕、音效和音乐分层记录。
- [ ] 字幕与旁白同步，断句适合阅读，位置不遮挡主体。
- [ ] 音乐不会盖住人声，重点音效有明确入点。
- [ ] 音频来源和授权状态已确认。

## 交付与安全

- [ ] 已列出画幅、分辨率、帧率、格式和音频参数。
- [ ] 已标记默认值、已确认内容和待确认内容。
- [ ] 没有未经用户确认的收费调用、上传、发布或自动接单。
- [ ] 没有编造素材来源、授权、模型结果或历史事实。
