# 国风3D动画短片提示词规格生成器

当用户想把一句话创意做成完整的故事优先国风动画短片的提示词规格（spec）时使用本 Skill。流程从创意开发到产出可交付给图像/视频生成工具的提示词，所有主要产物都必须按生产顺序放到画布上，并在高成本或关键创意节点用选项卡让用户确认。本 Skill 只生成提示词与规格，不直接生成图像、视频或拼接成片。

核心规则：**先故事、再提示词；信息不足先问用户，不臆造（缺片名、署名、比例、时长、台词模式时必须询问）；用户输入内容后立刻用选项卡确认画面尺寸/比例、总时长与片头标题段时长；产物按顺序上画布；所有需要用户确认的地方必须用选项卡；每一份角色卡、场景卡、片头标题段、分镜与视频提示词都必须携带全局视觉风格锁；角色/场景卡提示词后固定顺序为：首个分镜开头 3–5 秒的片头标题段，并入 S01 而不单列分镜（可选用已批准角色/场景作主题背景；逐字片名+署名，字体未指定则随机二选一，同一镜头内自然转入剧情）→ 六列标准镜头信息表（S01 为首行，开头为片头标题段；每秒指令+音频+空间锚点链+hook）→ 镜头表自检门 → 一份单一文本分镜文档（S01 为第一节，片头标题段作为 S01 章节的首个区块；对齐半解说短剧分镜字段；用户主动开启可视化模式时再加铅笔图；用户标记需要重点迭代的镜时抽取成独立节点）→ 视频模型选项卡（H3 默认，Seedance 2.0 回退）+ 分辨率选项卡 → 逐镜生成单镜头视频提示词（S01 优先，优先走 h3-prompt-writing 技能；H3 默认 Ref2VA，角色卡/场景卡作为全局参考素材）；本 Skill 只输出提示词与规格，不生成图像、视频或成片**。

## 全局视觉风格锁

除非用户明确指定其他视觉风格，所有角色卡提示词、场景卡提示词、镜头表格、文本分镜、可选铅笔分镜、单镜头视频提示词（无论面向哪个视频模型）都必须使用以下视觉风格。风格锁只约束"怎么画"，不约束"画谁"——角色的性别、年龄、面容、发色发型、服装款式、配饰、身份与世界观设定全部来自故事，不得把任何参考图中的人物造型套进提示词。

- 渲染体系：影视级国风写实 CG，次世代游戏过场动画 / 动画电影级质量；路径追踪全局光照、物理可信的材质响应、电影级调色；画面干净通透，带极轻微胶片颗粒。不是卡通渲染，不是扁平二次元。
- 人物写实度：写实向理想化比例（接近真实人体比例与东亚面孔骨相），面部结构扎实、五官精致克制、神态含蓄；不做 Q 版大头、不做几何概括、不做夸张变形。
- 皮肤：瓷白细腻的低饱和肤色，次表面散射让耳廓、鼻尖、指尖透出微红；保留毛孔与绒毛级微观细节，高光柔和过渡；忌塑料感与过度磨皮。
- 头发：单根发丝级渲染，高密度、有重量、有丝缎光泽；侧逆光下发丝边缘透光，保留细碎飞发，发梢自然收尖分层；不做块状卡通发片。
- 材质语言：纱、绡、丝绸的半透明叠层，边缘薄透、层次分明；刺绣、珠饰、玉饰、银饰带真实微高光与细腻反光；布料有真实重量、垂坠感与随风摆动。
- 色彩体系：低饱和东方色系——月白、霜青、雾蓝、藕荷、浅金、墨青；大面积负空间留白；禁止高饱和糖果色与荧光色。
- 光照体系：高位柔和主光 + 纱衣透射逆光 + 发丝轮廓光；体积雾、柔焦、轻微光晕；高调低对比，暗部通透不死黑；光尘微粒在光中清晰可见。
- 大气与景：水墨式远山、薄霭、静水涟漪、飘落花瓣 / 雪晶 / 光尘等东方仙气元素；强空气透视，远景以墨色层次逐渐消隐。
- 镜头语言：电影级浅景深（85mm / 135mm 人像镜头感）；运镜稳定或极缓（缓推、缓摇、轨道环移、升降），留白与对称 / 三分平衡的东方极简构图，画面有静气。
- 表演语言：写实、克制、内敛；情绪由眼神、呼吸、微表情、姿态重心，以及衣袂与发丝的次级动态承载；动作有真实重量、惯性、跟随与缓冲；不夸张变形。
- 负向风格约束：不要皮克斯 / 迪士尼卡通、不要 Q 版、不要塑料玩具皮肤、不要扁平二次元、不要高饱和糖果色、不要赛博霓虹、不要游戏 UI / HUD、不要欧美奇幻造型、不要真人实拍的杂乱现场感、不要僵硬木偶姿势、不要无生命表情。

默认世界观风味为古风仙侠 / 国风。若故事设定不在东方古典世界，保留渲染、色彩、光照、表演与镜头五项风格锁，将服装与环境材质适配故事设定，但不得回退为卡通或写实真人摄影。

风格锁核心词串（撰写每条图像 / 视频提示词时原样附加）：

- 中文：`国风仙侠影视级写实CG，次世代过场动画质感，低饱和月白霜青色系，柔和体积光，纱衣透射逆光，发丝级细节，水墨远山薄霭，电影级浅景深，东方极简留白构图，高调低对比，轻微胶片颗粒`
- 英文：`cinematic Chinese guofeng photoreal CG, next-gen game cinematic quality, desaturated moon-white and frost-blue palette, soft volumetric lighting, translucent silk backlight, strand-level hair detail, ink-wash mountain haze, shallow filmic depth of field, minimalist oriental negative-space composition, high-key low contrast, subtle film grain`

## 片头标题段（强制，置于 S01 开头）

每次交付都在首个分镜内呈现片头，而不是单列一个镜头：S01 开头先用 3–5 秒标题段逐字展示片名与署名，可引用已批准角色/场景作主题背景，并在同一镜头内自然转入 S01 的剧情动作。

- 逐字文本：片名与署名按用户给出的原文逐字呈现。用户未提供时先询问并等待。不得自行编造、翻译、缩写、转写或改写；用户给出的署名格式（如"作者："、"A film by"、笔名）必须原样保留。
- 主题背景（可选）：标题段可以引用已批准素材作主题背景——最多 1 张场景卡、最多 2 张角色卡。引用时必须记录精确卡名，锁定身份与环境。引用只能停留在主题层：静态环境、平静肖像、背影或剪影、失焦身影；不得出现剧情动作、互动、对白、剧情事件、剧情预演，也不得出现绑定卡之外的剧情道具。被引用角色不表演，只存在于画面中。背景必须服从字体（虚焦、低对比、留白），人脸不得压住片名文字区。未引用任何卡时，只使用全局视觉风格锁的氛围元素（水墨、薄雾、纱、光、粒子、远山剪影）。
- 字体样式：用户已指定则用指定样式；未指定时，从以下两种中随机二选一，并把选择记录到项目简报与 S01 分镜：(a) **泼墨豪放手写**——湿墨晕染、笔势豪放、纸面高对比；(b) **尖角刀锋艺术字**——尖锐收锋、刀锋笔画、硬朗利落。选定后跨重试保持一致，仅在用户要求时更换。两者不得混用，不得跳过选择。
- 字体排版：片名为主、署名为辅；字色、字级、位置必须与画面协调；整个 3–5 秒标题段内保持可读。
- 时长：S01 开头 3–5 秒（从 `0s` 到 `3–5s`），默认 5 秒，用片头标题段时长选项卡确认。
- 段内衔接（强制）：明确写出从标题段转入 S01 剧情动作的转场方式（水墨溶解 / 雾幕擦除 / 光晕匹配剪辑 / 片名溶解 / 连续推镜穿透），并让标题段最后一帧的构图、光位基线、粒子状态与镜头运动自然收束到剧情动作首帧。不得硬切，剧情动作在标题段之后、同一镜头内开始。
- S01 时长：S01 的计划时长必须同时覆盖标题段与剧情节拍，标题不得取代或截断剧情节拍。若标题段会使 S01 超过 15 秒，就在 3–5 秒内缩短标题段，或把剧情节拍移到其他镜头——绝不把片头拆成独立分镜。
- 交付物：没有单独的 `片头分镜` 节点，没有单独的片头镜头，也没有单独的视频提示词。标题段设计写在项目简报、S01 表格行、S01 分镜章节与 S01 视频提示词中。若产出首帧图像提示词，那是 S01 的开场首帧图（默认 Qwen-Image，含已确认画幅 + 风格锁 + 逐字文本 + 选定字体 + 可含已绑定的主题场景/角色卡 + 负向：标题段无剧情动作、无多余文字、无水印、无绑定卡之外的人物），不是独立片头镜头。

片头标题段最小字段：

- 段落标题 & 时间：`S01 opening title segment / 0–<3–5>s — <片名>`
- 字体块：逐字片名 / 逐字署名 / 字体样式（用户指定或随机选中）/ 层级 / 位置 / 入场与出场动效
- 视觉：背景概念（可以是引用的场景卡）、氛围层、色彩、光位、一条连续运镜
- 主题引用（可选）：场景卡名、角色卡名，以及各自用法（环境静帧 / 平静肖像 / 剪影 / 失焦身影）与契合片名主题的理由
- 每秒指令：标题段每秒覆盖文字入场或停留、背景动态、镜头、音频、段内交接
- 段内衔接：转入 S01 剧情动作的转场名称 + 匹配的首帧状态（构图、光位、运动）
- 绑定：`characters: none | <精确卡名>`、`scene card: none | <精确场景卡名>`
- 标记：S01 内标 `[TITLE-SEGMENT]`；S01 的 Hook 类型仍是其剧情 hook，同时必须承载片名揭示

## STEP 0：接收需求与画布规划

捕捉：

- 一句话创意或粗略故事
- 目标产物：始终包含 S01 开头的片头标题段；此外可为只要蓝图、角色卡图像提示词、场景卡图像提示词、六列标准镜头信息表、单文本分镜文档（默认）+ 重点迭代镜抽取的独立节点 + 多宫格铅笔分镜（开启可视化模式时）、单镜头视频提示词（面向的视频模型在 Step 7 选定）。本 Skill 只产出提示词与规格，不产出最终图像或视频
- 用户已说明的预估时长
- 用户已说明的画面尺寸 / 比例
- 视觉基调：默认国风仙侠影视级写实 CG（月白霜青冷调），遵循全局视觉风格锁

- 只有用户明确指定台词语言时才锁定语言；不要默认英文台词
- 精确片名（逐字）
- 精确署名与署名格式（逐字，含用户要求的前缀）
- 用户已说明的片头标题段时长（限定在 3–5 秒）
- 用户如提供风格参考图：只提取渲染方式、色彩、光照与氛围，绝不复制图中的人物、发型、服装或道具

信息不足规则：故事前提、精确片名、精确署名、画面尺寸/比例、总时长、台词模式任一缺失时，先询问用户并等待，不得臆造、推断或静默取默认值。唯一例外是字体样式——未指定时按片头标题段规则随机选择。

总时长选项卡：

- 30–60 秒（推荐）
- 15–30 秒
- 60–90 秒
- 90–180 秒
- 自定义时长

片头标题段时长选项卡：

- 3 秒
- 4 秒
- 5 秒（推荐）
- 自定义时长（须在 3–5 秒内）

只有用户同时选择画面尺寸/比例和总时长，或明确给出自定义值后，才进入下一步；片头标题段时长在同一轮确认（3–5 秒，用户未指定时默认 5 秒）。把已确认的画面尺寸/比例、总时长、片头标题段时长写入项目简报，并贯穿用于镜头时长、转场连贯性、六列标准镜头信息表、单镜头分镜（默认文本，开可视化模式时含铅笔图）和单镜头视频提示词。

按以下顺序创建或更新画布产物：

1. 项目简报文本节点
2. 故事大纲文本节点
3. 角色卡图像提示词文本节点
4. 无人物的场景卡图像提示词文本节点
5. **S01 内的片头标题段** — 不单列产物：精确片名与署名占据 S01 开头 3–5 秒，可选角色/场景作主题背景，并以命名段内转场转入 S01 剧情动作
6. 六列标准镜头信息表节点，S01 为首行且以片头标题段开场（随后在 `镜头描述` 内接剧情每秒指令）
7. **单文本分镜文档** — 一个画布文本节点，命名 `<title> text storyboards`，按镜头顺序每镜一节，从 S01 开始；S01 章节以片头标题段区块开头（对齐半解说短剧分镜结构）。用户标记需要重点迭代的镜时，把该节抽取成独立节点，原位置留占位。可视化模式下的铅笔分镜图是独立图片节点。
8. **H3 全局参考素材清单** — 仅选择 H3 时：画布文本节点 `全局参考素材清单` / `global-reference-manifest`，把每张已批准角色卡/场景卡映射到稳定的 `<Subject N>`，记录精确卡名、卡图（或 `pending`）与出现镜头
9. 单镜头视频提示词文本节点，S01 优先（面向 Step 7 选定的视频模型 — H3 默认，Seedance 2.0 回退；H3 提示词为 Ref2VA 并绑定清单中的卡图）

不要把长篇生产内容只丢在对话里。耐用产物必须以文本节点形式落到画布。

## STEP 1：项目简报

- 精确片名（逐字）
- 精确署名与署名格式（逐字）
- 片头标题段方案：时长（3–5 秒）、字体样式（用户指定或随机选中）、从 S01 开头 `0s` 转入剧情的段内转场方式；无独立片头镜头
- 一句话 What-if
- 情绪前提
- 目标观众感受
- 主要交付物计划
- 已确认的画面尺寸 / 比例
- 已确认的总时长
- 已确认的视觉风格（默认：国风仙侠影视级写实 CG，遵循全局视觉风格锁）

- 初始风险
- 台词意图（如有）

然后展示用户选项卡：

- 沿用此方向继续（推荐）
- 重新生成前提选项
- 修订情绪前提
- 调整台词方向

只有用户选择或明确说继续后才进入下一步。

## STEP 2：故事大纲与守门

创建故事大纲并写入画布文本节点，命名为 `故事大纲` 或 `story-outline`。

包含：

- 主角 Want / Need / 缺陷
- 核心世界规则
- 8 拍因果故事骨架
- 情绪锚点与回收
- 台词节拍（用户要求时）
- 红线检查

守门检查：

- 主角是主动的
- 危机由主角缺陷放大
- 巧合不能解决问题
- 结局回收早前情绪锚点
- 反派压力不是扁平反派
- 台词揭示关系变化而非解释主题

然后展示用户选项卡：

- 批准故事并继续（推荐）
- 修订节拍
- 修订情绪曲线
- 修订台词节拍
- 返回前提

## STEP 3：角色卡图像提示词

编写角色卡图像生成提示词，并把每份提示词作为文本节点放到画布。推荐顺序：

1. 主角卡提示词
2. 对比 / 施压角色卡提示词
3. 可选配角卡提示词

每份角色卡提示词，交给图像生成模型后应能产出一张 16:9 的生产参考图。提示词必须要求模型在图内包含清晰可读的标注，让下游生成能正确绑定人物与道具：

- 角色名标注（英文和/或项目语言）
- 角色定位标注：主角、长辈、反派、搭档、施压角色等
- 主 3/4 视角
- 正 / 侧 / 背三视图
- 表情
- 材质 / 服装 / 道具细节
- 重要道具标注：剑、灯笼、团扇、玉佩、发簪、卷轴、鞋履、面纱等
- 提示中重复的"身份锁"
- 简短视觉 ID 备注：年龄段、身材、发型、服饰色、签名道具、不可改特征

本风格下，要提示模型保持角色的面容、比例、材质与造型在跨图跨视频中出现一致的写实 CG 可信度。不得从任何参考图带入模板脸、固定发型或固定服装；角色设计完全来自故事。

生图模型默认：若用户未指明生图模型，则按 **Qwen-Image** 编写提示词，写成一份自洽的 Qwen-Image 图像生成提示词，能复现上述角色卡（含全局视觉风格锁、风格锁核心词串、全部标注、三视图、材质/道具细节、身份锁与视觉 ID 备注）。若用户指定了其他生图模型，则按该模型编写。

主要角色卡提示词写完后展示用户选项卡：

- 锁定角色设计并继续（推荐）
- 重新生成主角卡提示词
- 调整具体视觉细节
- 增加另一张角色卡提示词

警告用户：后续修改已锁定的角色设计可能需要重做镜头表、单镜头分镜和单镜头视频提示词。

## STEP 4：场景卡图像提示词

在角色卡提示词之后编写场景卡图像生成提示词并放到画布。场景卡提示词只能描述环境，不出现人物、人群、剪影、手、脸或角色客串。角色动作属于镜头表、单镜头分镜与单镜头视频提示词，不属于场景卡提示词。

每份提示词包含：

- 主环境总览
- 关键光态：晨光 / 黄昏 / 月夜
- 情绪子空间
- 连续性地标（同场景跨镜头必须保持屏幕位置的固定物体，如石桥、亭柱、影壁、古树、祭台）
- 环境中的重要道具
- 与风格锁一致的大气层细节：薄雾、水面涟漪、飘落花瓣、光尘等

生图模型默认：与 STEP 3 一致，若用户未指明生图模型，则按 **Qwen-Image** 编写提示词，写成一份自洽的提示词，能复现上述场景卡并包含全局视觉风格锁与风格锁核心词串。若用户指定了其他模型，则按该模型编写。

然后展示用户选项卡：

- 锁定场景设计并继续（推荐）
- 重新生成场景卡提示词
- 增加另一个场景角度
- 调整光位或布局

## STEP 4.5：片头标题段设计（并入 S01）

在镜头表之前设计强制的片头标题段，但不为它单列镜头、节点或提示词。标题段是 S01 的前 3–5 秒；S01 的剧情动作在同一连续镜头内紧随其后。

必读参考：遵循上方"片头标题段（强制，置于 S01 开头）"小节的逐字文本、字体随机、排版、时长与段内衔接规则。

最小运行契约：

- 不创建 `片头分镜 S00` 节点，也不产出单独片头关键帧；标题段设计记录到项目简报。
- 使用项目简报中已确认的精确片名与署名；用户未提供时停下来询问。
- 用户已指定字体样式则直接使用；未指定则从泼墨豪放手写 / 尖角刀锋艺术字中随机二选一，并把选择记录到项目简报。
- 最多绑定 1 张场景卡与 2 张角色卡，且仅作主题背景；记录精确卡名，未引用时写 `none`。被引用角色保持静止或近乎静止（平静肖像、背影、剪影、失焦身影），不得表演剧情动作。
- 标题段固定在 S01 的 `0s` 起，持续 3–5 秒（使用已确认的片头标题段时长）。
- 明确命名从标题段转入 S01 剧情动作的段内转场，并说明标题段最后一帧（构图、光位基线、粒子状态、镜头运动）如何收束到剧情动作首帧。
- 确认 S01 计划时长覆盖标题段 + 剧情节拍；若超过 15 秒，就在 3–5 秒内缩短标题段或把剧情节拍移到其他镜头——绝不把片头拆成独立分镜。
- 若产出 S01 首帧图像提示词，它是 S01 的开场首帧（标题段帧），不是独立片头镜头。

然后展示用户选项卡：

- 批准标题段设计并进入镜头表（推荐）
- 调整主题背景（选择场景/角色卡或留空）
- 换成另一种字体样式
- 修改片名或署名（由用户提供精确文本）
- 调整标题段时长（3–5 秒内）
- 调整转入 S01 剧情动作的段内转场

## STEP 5：六列标准镜头信息表

在角色卡、场景卡与片头标题段设计锁定后，输出标准化视频提示作为镜头信息表。本步为强制步骤，不可与分镜或视频生成互换。在画布创建表格节点或 markdown 表格，命名为 `标准镜头信息表` 或 `standard-shot-table`。

表格必须严格按以下顺序包含六列：

| 镜头编号 & 时长 | 连续性衔接 | 参考锚点（空间+身份） | Hook 类型 | 镜头描述（每秒指令） | 音频与对白轨 |
|---|---|---|---|---|---|

列规则：

- **首行 S01**：表格第一行是 S01。其 `镜头描述` 必须先放 STEP 4.5 的 `片头标题段（0–3/5s）` 区块——逐字片名与署名、字体入场/停留、可选主题场景/角色背景、以及转入剧情动作的段内转场——然后无时间空隙地接 S01 剧情的每秒指令。S01 的 `Hook 类型` 是它的剧情 hook，不是 `title-card`；S01 必须同时承载片名揭示与本镜剧情 hook。身份绑定写 `characters: none | <精确卡名>`、`scene card: none | <精确场景卡名>`；标题段的主题引用与 S01 剧情动作的在屏角色分开记录。
- **镜头编号 & 时长**：镜头号加计划时长，例如 `S03 / 6s`。
- **连续性衔接**：本镜如何自然承接上一镜的结束画面、道具位置、眼神、人物姿态、声桥或情绪状态；以及本镜如何为下一镜开篇铺好钩子。这是跨镜连续性主链。
- **参考锚点（空间+身份）**：四个子字段，全部必填。
  - `固定地标` — 来自场景卡的确切命名地标，及其相对画面的位置（如 `stone-bridge: 右侧 1/3`、`altar: 底部居中`）。
  - `人物位置（机位视角）` — 镜头中每个角色相对画面的位置（左/中/右、上/中/下、前/中/后景）、朝向、初始姿态。
  - `退场人物状态` — 上一镜有但本镜没有的角色，记录其离屏位置和原因（如 `女主 — 离屏左侧，最后出现于石桥旁持灯`）。
  - `光位基线` — 从场景卡继承的主光/补光/轮廓光方向，加本镜调整项（如 `主光：高位柔光，补光：右侧冷反光，调整：纱衣逆光透射`）。
  - 加上身份绑定：已批准的角色卡名（精确）和场景卡名（精确）。
- **Hook 类型**：从受控词表中挑一个短标签，如 `visual-joke`、`reversal`、`suspense`、`tender`、`chase`、`reveal`、`callback`、`expression-beat`；S01 也用它自己的剧情 hook（片名揭示作为 S01 内的附加信息写进 `镜头描述`，不占用 hook 词表）。用于整片 hook 分布自检。
- **镜头描述**：景别、镜头运动、荷兰角设计、表演风格、音效、负向提示、**视频模型生成备注**（Step 7 选定的模型 — H3 或 Seedance 2.0 — 接收的 prompt 形态略不同；H3 强调氛围/美术包装、粒子与动效清晰度，Seedance 2.0 强调电影感镜头、复杂调度与写实动作），并强制包含 `Per-Second Directives` 子节。子节必须按秒拆解为 `0–1s`、`1–2s`、`2–3s` 等指令；亚秒关键节拍用 `2.0–2.5s` 风格标记。每条每秒指令必须覆盖全部 5 个必填要素：
  1. 动作 / 姿态 / 表情（重心转移、呼吸、预备与跟随、衣袂与发丝次级动态、微表情变化）
  2. 镜头运动（缓推 / 缓拉 / 缓摇 / 缓倾 / 极轻微手持 / 锁定 / 环移）
  3. 空间位置（人物在哪、持有什么、地标在画面哪里）
  4. 音频线索（旁白 / 对白 / 音效 / 呼吸 / 沉默 — 或 `silent` 表示有意静默）
  5. 与下一秒或下一镜的交接（这一秒锁定的状态如何递给下一秒）
- **音频与对白轨**：本镜完整音频脚本，按时间顺序，独立于每秒指令。字段：
  - `旁白` — 旁白文本及时间范围（无旁白则省略）。
  - `对白` — 台词、说话人、语气、时间范围。
  - `音效` — 关键音效，按时间锚定。
  - `表演备注` — 主角离屏旁白时标记 `narrator-mouth-closed: true`；描述旁白期间表情路径；描述每条对白的具体眼神和身体动作变化。

表格全局规则：

- 每镜必须通过 `连续性衔接` 列自然继承上一镜画面状态，并为下一镜做铺垫。
- 每镜必须含覆盖整个时长的每秒指令，包含动作、姿态、表情、镜头运动、空间位置、音频线索和连续性交接。
- 每秒指令必须具体到可直接生成分镜面板；避免"继续移动"这类缺少身体/镜头/道具细节的模糊描述。
- 表演必须写实、克制、有重量：预备、跟随、缓冲、重叠动作完整，动作清楚可读；情绪主要由眼神、呼吸、微表情、姿态重心与衣袂发丝的次级动态承载，不做挤压拉伸式夸张变形。
- 景别必须在特写 / 大特写与其他必要景别间交替；避免重复景别。
- 荷兰角构图只为失衡、压迫、惊吓或强冲击节拍设计，且在本风格中克制使用，不用于喜剧闹剧。
- 台词语言仅在用户明确要求时使用；否则用最小化非语言特定反应或将台词标记为可选 / 待确认。
- 含旁白或对白的镜头，每一秒人物说话时都必须记录嘴部开合；默认离屏旁白为闭，对面对白为开。
- 已离屏角色在 `退场人物状态` 至少记录 1 镜，连续 2 镜明确不在场后再移除。

然后展示用户选项卡：

- 批准表格并进入自检（推荐）
- 调整镜头连续性
- 加强表演张力与动态层次
- 调整特写 / 大特写节奏
- 调整荷兰角设计

## STEP 5.5：镜头表自检门（强制）

进入分镜前，必须对已批准的镜头表跑硬性自检。任何一项不通过必须先修订表格再重跑，通过后才向用户申请进入分镜。

七项必检：

1. **Hook 密度**：每镜都有 `Hook 类型`；从 S01 起每连续 3 个剧情镜至少 1 镜使用 `reveal`/`reversal`/`callback`；S01 与收尾镜各带强 hook（`visual-joke` / `reversal` / `reveal` / `suspense` / `tender`）。S01 同时承载片名揭示，但片名揭示不单独占用 hook 词表，S01 仍必须给出自己的剧情 hook。
2. **单镜时长**：任何镜头不超过 15 秒。节拍需要更长就拆镜。
3. **单镜角色数**：任何镜头不超过 3 个重要角色（定义为有画面动作或对白的角色）。
4. **空间锚点继承**：含 2 镜以上的同场景，下一镜的 `固定地标` 和 `光位基线` 必须与上一镜一致或含明确连续性备注（如 `stone-bridge 随镜头左环移由右侧 1/3 移至中央`）。
5. **每秒指令覆盖**：从 `0s` 到镜尾的每秒都有 `Per-Second Directives`，每条含 5 个必填要素（动作/姿态/表情、镜头、空间、音频线索、交接）。允许 `2.0–2.5s` 亚秒节拍但不能留时间空隙。
6. **跨镜连续性**：逐行读 `连续性衔接` 列必须形成连续链，并且从 S01 的剧情动作开始 — S01 的 `0s` 是标题段，标题段自身必须无空隙转入剧情动作；其后任何一镜都不能从一个与上一镜结束矛盾的状态起步。任何翻转眼神、人物位置、道具状态或光位的镜头必须明确标记翻转（如 `HARD CUT — 时间跳 2h`）。
7. **片头标题段完整性**：表格首行为 S01，没有 S00；S01 的 `镜头描述` 以 `片头标题段（0–3/5s）` 区块开场；片名与署名与用户确认的逐字文本完全一致；字体样式已记录，且仅为泼墨豪放手写 / 尖角刀锋艺术字之一（或用户明确指定的样式），未混用；如引用角色/场景，卡名精确且仅作主题背景（静态环境 / 平静肖像 / 剪影 / 失焦身影），无剧情动作、无对白、无绑定卡之外的剧情道具，未引用则记为 `none`；标题段固定在 S01 开头 3–5 秒并停留到可读；字体仍为画面主体；标题段以明确命名的段内转场转入 S01 剧情动作，构图 / 光位 / 粒子 / 运动匹配；S01 总时长覆盖标题段 + 剧情节拍且不超过 15 秒。

七项全过后，在画布表格节点顶部加 `shot-table self-check: passed` 戳，并展示用户选项卡：

- 批准自检并绘制分镜（推荐）
- 查看自检详情
- 修订失败项
- 重新跑自检

任何一项不通过就不进入 Step 6。返回 Step 5，列出失败行，表格修好并重跑自检通过后，才能再次展示分镜批准选项卡。

## STEP 6：单文本分镜文档（默认）+ 多宫格铅笔分镜图（opt-in）

Step 5.5 自检通过后，先展示分镜模式选项卡，再生成任何分镜产物：

- **单文本分镜文档（默认，推荐）** — 整个短片一份画布文本节点，所有分镜（S01 起剧情镜，S01 开头内嵌片头标题段）作为文档内章节。对齐半解说短剧分镜结构：每镜字段（标题/hook/场景/角色/空间锚点/连续性/表演备注）加每面板四象限内容 + 可选 ASCII 布局。承载完整质控载荷，成本几乎为零。Step 7 选定的视频模型直接读取作为该镜提示词写作参考。
- **单文本分镜文档 + 多宫格铅笔图（可视化模式，opt-in）** — 单文本分镜文档照常作为权威产物，并额外为每镜生成一张多宫格铅笔图供人眼审稿。S01 的前几个面板画出片头标题段的版式、字块与可选主题背景（角色/场景仅作静态占位），不另出独立片头图。成本更高，适合用户想在付视频成本前要一次视觉预演，或表演重量、衣袂发丝次级动态、姿态剪影是高风险项想先可视化检查的情况。

把选中的分镜模式记入项目简报，并在 Step 7 里复用。

### 默认路径：单文本分镜文档

为整部短片生成一个画布文本节点，命名 `<title> text storyboards`（一个文档包含所有分镜）。即使同时生成铅笔图，这份文档仍是 Step 7 的权威提示词写作参考。结构对齐半解说短剧分镜 —— 每镜是同一文档的章节，用户读跨镜连续性不需要切换节点。文档从 S01 开始；S01 章节以片头标题段区块开场，随后接 S01 的剧情面板，不设 S00 章节。

文档头部块（文档顶部）：

- 项目标题、已确认的视频模型、已确认的分辨率、分镜模式、自检状态（如 `shot-table self-check: passed at <时间戳>`）、已确认的视觉风格（国风仙侠影视级写实 CG）、片头标题段字体样式、片头标题段主题引用（场景/角色卡名或 `none`）。
- 一段简短的目录，列出 S01 与每镜的 hook 和章节锚点（如 `S01`、`S02`、`S03` …），便于用户跳转。

### S01 片头标题段区块（强制，S01 章节开头）

S01 章节的第一块固定为片头标题段，必须包含：

- **段落标题 & 时间**：`S01 opening title segment / 0–<3–5>s — <片名>`。
- **字体块**：逐字片名 / 逐字署名 / 字体样式（用户指定或随机选中）/ 层级 / 位置 / 入场与出场动效。
- **视觉**：背景概念、氛围层、色彩、光位、一条连续运镜。
- **空间锚点卡**：未引用场景卡时固定地标 / 人物位置 / 退场人物均为 `none`；引用场景卡时继承其固定地标与光位基线，并标注为主题层（虚焦、低对比）；引用角色卡时记录画面位置、景别与静止主题姿态（肖像 / 背影 / 剪影 / 失焦）；光位基线 = 风格锁氛围光 + 与剧情动作首帧匹配的光位。
- **段内衔接**：转入 S01 剧情动作的转场名称 + 标题段最后一帧如何匹配剧情动作首帧（构图 / 光位 / 粒子 / 运动）。
- **双绑定**：`[char:none | <卡名>] [scene:none | <场景卡名>] [hook:<S01 剧情 hook>]`。
- **每面板四象限内容**：按秒覆盖文字入场 / 停留、背景动态、镜头、音频 + 锚点、字体动效备注。
- **绑定**：可选引用最多 1 张场景卡与 2 张角色卡作主题背景，记录精确卡名；未引用写 `none`。
- **分镜专用标记**：字体入场用 `[TYPE-IN]`，片名揭示用 `[TITLE-REVEAL]`，段内交接用 `[HANDOFF → S01 story action]`。

### 每镜章节结构（S01 起，每个 `##` 标题对应一镜，按镜头顺序）

每个 S01 起的章节在片头标题段区块之后（该区块仅 S01 有），必须按以下顺序包含这些字段 —— 直接对应半解说短剧的分镜字段：

1. **镜头标题 & 时长** — 简短可读的本镜标题，加 `S<N> / <duration>s`（如 `S03 / 6s`）。
2. **Hook 类型** — 受控词：`setup` / `visual-joke` / `reversal` / `reveal` / `callback` / `suspense` / `tender` / `chase` / `expression-beat` / `climax`。用于整片 hook 分布自检。
3. **场景 & 角色** — 精确场景卡名、精确在屏角色名（绑定到角色卡）。
4. **空间锚点卡**（强制，四个子字段 —— 直接对齐半解说短剧）：
   - `固定地标` — 命名地标及其画面相对位置（如 `stone-bridge: 右侧 1/3`、`altar: 底部居中`）。
   - `人物位置（机位视角）` — 每个在屏角色，画面相对位置、朝向、初始姿态。
   - `退场人物状态` — 上一镜有但本镜没有的角色，记录其离屏位置和原因。
   - `光位基线` — 从场景卡继承的主光/补光/轮廓光方向，加本镜调整项。
5. **连续性**（对齐半解说短剧的 handoff 字段）：
   - `承接 S(N-1)` — 一两句话交代上一镜结束状态。
   - `交接 S(N+1)` — 一句话铺好下一镜开场。
6. **双绑定** — `[char:角色名-01] [char:角色名-02] ... [scene:场景名] [hook: visual-joke]` — 精确角色卡名、场景卡名、hook 类型。这些是分镜专用参考标记，生成视频提示词时剥离。
7. **每面板四象限内容**（按时间顺序；这就是每秒指令，从表格行原样保留）：
   - `时间码` — 如 `0–1s`。
   - `姿态 + 表情` — 具体身体姿态、剪影、关键持握、眼神、表情路径；关键节拍明确写出重心转移、预备、跟随、衣袂与发丝次级动态。这是每面板最大块内容，也是视频模型读取的视觉节拍。
   - `镜头` — 景别、镜头运动（缓推/缓拉/缓摇/缓倾/极轻微手持/锁定/环移）、荷兰角备注。
   - `音频 + 锚点` — 音频线索（`♪ 旁白: ...` / `对白: ...` / `SFX: ...` / `silent`）和空间锚点备注（`stone-bridge: 右侧 1/3` / `女主: 中央中景面朝镜头`）。
   - 表演备注（对齐半解说短剧）：旁白秒标 `narrator-mouth-closed: true`；面对白秒标 `mouth-open: speaker` 并描述表情路径 / 眼神 / 身体动作变化。
8. **布局规则**（逐镜适用）：
   - 3 秒镜 → 3 面板（每秒 1 个）。
   - 4 秒镜 → 4 面板。
   - 5 秒镜 → 5 面板。
   - 6 秒镜 → 6 面板。
   - 7 秒及以上 → 每秒 1 面板；亚秒关键节拍按需加迷你面板如 `2.0–2.5s`，仅当该节拍是本镜核心 hook 时。
   - 面板必须覆盖整镜时长，从首帧到尾帧无时间空隙。
9. **每面板绑定**：
   - 绑定表格行中列出的精确角色卡，锁定外观、脸、发型、身材、服装、签名道具、角色身份。使用与表格相同的角色名。
   - 绑定表格行中列出的精确场景卡，保留环境、道具、地标、运动路径、空间逻辑。
10. **可选 ASCII 布局块（强烈推荐，零成本）**：
    - 每面板附一小段 ASCII 草图（或整镜一张组合草图），让用户秒扫空间布局而不必渲染图。例：
      ```
      [0-1s]  女主 (L, mid)         stone-bridge (R)
              ——跪坐，双手扶灯——
              cam: slow push-in, locked
              audio: silent | anchor: lantern center-bottom
      [1-2s]  ...
      ```
    - ASCII 块仅供参考；视频模型读取上面结构化的 `每面板四象限内容`，不读 ASCII。
11. **分镜专用标记**：
    - S01 在镜头标题后加 `[TITLE-SEGMENT]` 标出片头标题段。
    - 关键节拍在面板时间码后加 `[BEAT]`。
    - 某面板必须交接特定状态到下个面板或下个镜头时，加 `[HANDOFF → ...]` 短标签，如 `[HANDOFF → S04 opening]`。

每镜章节模板（任意镜通用，复制粘贴骨架）：

```markdown
## S03 / 6s — 标题：女主在石桥上接过灯笼

- **Hook 类型**：reveal
- **场景 & 角色**：scene:moonlit-bridge | char:女主, char:引路人
- **空间锚点卡**：
  - 固定地标：stone-bridge（右侧 1/3）、lantern（底部居中）
  - 人物位置：女主（左，中景，侧身朝桥心）| 引路人（右，前景，背对镜头）

- **承接 S02**：引路人提灯踏上石桥，水面泛起涟漪

### ASCII 布局（可选）
```

所有章节写完后，把文档放到画布，直接进入 Step 7。默认模式下不要调用任何图像生成模型。

### 按镜抽取（重点迭代模式）

默认的单文档形态针对阅读和跨镜连续性做了优化。当用户标记某镜需要重点迭代（通常是 climax / 追逐 / 强情绪节拍，每面板内容需要多轮修订），就把该章节从文档中抽取成独立文本节点，让迭代局部化：

- **用户信号**：Step 6 之后任何时间用户说"重点改 S05"、"S05 需要返工"、"抽取 S05"、或在分镜批准选项卡选某镜做重点迭代。
- **抽取机制**：
  1. 新建一个画布文本节点，命名 `<title> S05 text storyboard (extracted)`。
  2. 把文档中 `## S05` 章节的完整内容移到新节点。
  3. 在文档中，把原 `## S05` 章节替换为一行占位：`> S05 — 已抽取到独立节点（见 \`<title> S05 text storyboard (extracted)\`）`。
  4. Step 7 写 S05 视频提示词时从抽取节点读取；其他镜仍从文档读取。
- **回填**：用户满意后，把独立节点折叠回文档（占位换成最新内容），独立节点归档。
- **多镜抽取**：每个被抽取的镜各自独立成节点，文档里用占位追踪。

抽取机制存在是因为独立节点按需使用才高效 —— 但只要迭代压力大就随时可用。

### Opt-in 路径：多宫格铅笔分镜图（可视化模式）

如果用户在分镜模式选项卡选了可视化模式，在单文本分镜文档之外**额外**为每行生成一张多宫格铅笔分镜图。单文本分镜文档仍为权威提示词写作参考；铅笔图仅供人眼审稿。

每张铅笔分镜图：

- **双绑定标签（右上角，强制写在图上）**：
  - `[char:角色名-01] [char:角色名-02] ...` — 本行用到的精确角色卡名。
  - `[scene:场景名]` — 精确场景卡名。
  - `[shot: S03] [dur: 6s] [hook: visual-joke]` — 镜头号、时长、hook 类型。
  - 这些标签是分镜专用参考标记，生成视频提示词时剥离。
- **绑定精确角色卡**，锁定人物外观、脸、发型、身材、服装、签名道具、角色身份。
- **绑定精确场景卡**，保持环境、道具、地标、运动路径、空间逻辑。
- 把行内每秒指令转换为一张分镜面板或一个明确标注的节拍面板：4 秒镜通常 4 面板；6 秒镜通常 6 面板；亚秒关键节拍按需加迷你面板。S01 的前几个面板画出片头标题段版式、字块与可选主题背景，标题段不单独出图。
- **面板物理排版（强制）**：
  - 3 秒镜 → 1×3 条。
  - 4 秒镜 → 2×2 网格。
  - 5 秒镜 → 上排 3 + 下排 2。
  - 6 秒镜 → 2×3 网格。
  - 7 秒及以上 → 3 排，面板均衡。
  - 每面板占据相同画布面积，不允许某面板独占。
- **每面板四象限内容（强制）**：
  - 左上：时间码（如 `0–1s`）。
  - 右上：姿态 + 表情草图（最大区域；实际视觉节拍）。
  - 左下：镜头图标 + 运动箭头（缓推/缓拉/缓摇/环移/锁定）加荷兰角小备注。
  - 右下：音频线索（如 `♪ 旁白: "我认得这盏灯。"` / `SFX: 灯纸轻响` / `silent`）和锚点备注（如 `stone-bridge: 右侧 1/3`）。
- 面板按阅读顺序排布，多个不同镜头不合并到同一图。
- 每面板标记时间码如 `0–1s`、`1–2s`，并展示对应姿态、表情、动作、镜头运动、道具位置、音效线索和连续性交接。
- 输出纯黑白铅笔线稿：不上色、不带最终渲染光、不带精致 CG 渲染。
- 在分镜图上标镜头号，必要时每面板加镜头运动图标 / 标记。
- 必要时包含分镜专用标记：铅笔结构线、动作箭头、镜头路径图标、时间标记和小注。
- 草稿只作为视频提示词参考资产，不是终稿美术。

### 分镜批准（两种模式通用）

所有文本分镜章节（和可视化模式下的铅笔图）产出后，按镜头顺序放到画布，归组为：
- `<title> text storyboards`（默认模式，单文档），或
- `<title> text storyboards + multi-panel pencil storyboards`（可视化模式，文本文档和铅笔图分两类各自归组，因为铅笔图含双绑定标签、ASCII 标签和镜头号，文本文档没有这些）。

展示用户选项卡：

- 批准分镜并生成镜头视频提示词（推荐）
- 抽取 / 回填某镜（在文档和独立节点之间移动章节）
- 重画选定的铅笔分镜（仅可视化模式）
- 修改片头标题段（片名 / 署名 / 字体 / 段内转场）
- 修复角色一致性
- 修复场景逻辑
- 修复镜头标记
- 修复音频/锚点标记

### 分镜生成失败回退（仅可视化模式）

如果铅笔分镜图无法按要求质量产出（布局塌陷、标签糊掉、面板合并、角色走样），在向用户求助前按以下升级路径处理：

1. **第一次重试**：用更紧的提示重画同一镜，明确写上四象限布局、`[char:…] [scene:…] [shot:…]` 标签和每面板内容规则。
2. **第二次重试**：去掉右下音频/锚点象限文字（保留为带小 `♪` 标记的空白格），减少文字负载；通常能修掉标签糊掉但不影响视觉节拍。
3. **第三次重试**：面板数减 1（例如 6 面板→5 面板，合并两秒动作最弱的秒），镜头图标简化为单箭头。
4. **同一镜连续 3 次失败后**：暂停并用选项卡问用户：
   - 切换为色块分镜（灰色方块占位姿态，不画铅笔线），仅限失败这一镜。
   - 放弃该镜的铅笔图，仅靠单文本分镜文档推进该行。
   - 在 Step 5 把该镜拆为两段更短的镜头并重跑 Step 5.5。
   - 手动提供参考图代替生成。

默认文本模式没有这套回退 —— 文本分镜失败只发生在模型无法产出连贯结构化文本时，遇到就直接回到 Step 5 修订该行表格。

## STEP 7：视频模型选项卡 + 生成单镜头视频提示词

### 视频模型选项卡（任何视频提示词生成前的强制门）

任何视频提示词生成前必须先展示视频模型选项卡。所选模型决定每镜提示词的格式。选择写入项目简报，本项目所有镜头沿用，除非用户后续修改。

视频模型选项卡：

- **H3（推荐默认）** — 强项是视觉包装、美术氛围、动效图形、文字/UI 清晰度、多模态上下文理解、性价比。原生双声道音视频。最适合：美术与氛围驱动的国风写实 CG 短片、粒子与雾效层、文字 / 字幕 / 片头片尾、对话驱动且音频就是交付物一部分的镜头。**提示词模式默认 Ref2VA，角色卡与场景卡作为全局参考素材。** 该模型的提示词使用 `h3-prompt-writing` 技能编写。
- **Seedance 2.0（高动态写实动作的回退）** — 强项是电影感镜头、复杂运镜、复杂调度、动作张力与写实物理。适合追逐、打斗、强情绪 climax 等以动作与镜头本身为卖点的镜头。
- **逐镜混合（高级）** — 在镜头表某行的 `镜头描述` 列加 `video_model: H3` 或 `video_model: Seedance2` 字段，本项目同时混用。未标记的行默认走 H3。

### 分辨率选项卡（视频模型锁定后）

视频模型确定后再展示分辨率选项卡，把分辨率写进提示词规格：

- 768P（H3 首推，性价比高）
- 2K（H3 默认质量，成本更高，画质更清）
- 1080p（Seedance 2.0 推荐）
- 720p（Seedance 2.0 草稿，最低成本）
- 匹配项目 / 自定义分辨率

首条视频提示词生成前用户必须先确认分辨率。后续用户可针对单条 hero 镜头临时改分辨率。

### 生成单镜头视频提示词

每行批准后，为该行编写对应的单镜头视频生成提示词。S01 最先写：从其片头标题段区块与剧情章节取内容，并使用已确认的片名/署名文本。之后每条提示词必须严格来自单文本分镜文档中匹配的章节（若该章节已抽取成独立节点则从独立节点取）、角色卡名和场景卡名。选用 H3 时，卡名对应全局参考素材清单中的卡图。

### H3 Ref2VA 全局参考合约（选择 H3 时的默认路径）

只要项目已有批准的角色卡或场景卡，H3 提示词默认走 Ref2VA，不用纯文本 T2VA。角色卡与场景卡是本项目的全局参考素材库，是身份与环境的权威来源，不是可选灵感。

1. **先建清单**：写第一条 H3 提示词前，创建画布文本节点 `全局参考素材清单` / `global-reference-manifest`，每张已批准卡一行：
   - `Subject ID` — 全项目稳定的 `<Subject N>`，一次性分配，角色卡在前、场景卡在后。
   - `卡类型` — 角色 / 场景。
   - `精确卡名`。
   - `卡图` — 已生成图片路径，或 `pending`。
   - `出现镜头` — 使用该卡的镜头号。
   清单是唯一事实源；同一 Subject 编号不得跨镜重排。
2. **每镜写成 Ref2VA**：六段顺序固定为 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music`。单镜头提示词只含一个 `[Shot 1]`。`h3-prompt-writing` 可用时必须按 full-reference 模式调用，并遵循其 Ref2VA 指南。
3. **绑定本镜用到的卡**：附上全部在屏角色卡 + 本镜场景卡；S01 另附其标题段引用的主题卡（剧情动作的在屏角色卡照常附）。提示词里 `<Picture N>` 是单次任务的附件本地编号，`<Subject N>` 保持全局编号。用卡图定义主体，例如 `<Subject 1> 是 <Picture 1> 中的角色…`；场景写作 `<Subject 3> 是 <Picture 2> 中的环境…`。有卡时不得用文字重新发明身份、服装或环境。确实无任何卡的镜头才可用 T2VA。
4. **保留分析**：角色对身份、面容、发型、身材比例、服装、标志性道具写 `fully_preserved`；场景对布局、地标、材质、光位基线写 `fully_preserved`；只有分镜明确改变时间/天气/光位时才用 `partially_preserved` 并说明变化。新增剧情动作不算参考保真度损失。
5. **S01 标题段例外**：S01 的片头标题段引用主题卡时写 Ref2VA；若剧情动作另有在屏卡，也一并附上。完全不引用任何卡时才用 T2VA；已有批准 S01 首帧图时可用 I2VA。片名/署名逐字与字体样式保持不变，标题段内被引用角色保持非表演。
6. **卡图未生成**：仍写 Ref2VA，并在清单中标记 `pending`；图片附上后提示词即可运行。只有用户明确拒绝参考图或确实无卡时才回退 T2VA，不得静默降级。
7. **参考数量预算**：若 H3 任务无法容纳全部附件，优先级为：在屏角色卡 → 本镜场景卡 → S01 标题段主题卡。不得静默丢掉主角卡；若限额必须取舍，拆分镜头或把取舍交给用户确认。
8. **混合模式**：只有 H3 行走本合约；Seedance 行按 Seedance 规则写。

各模型通用规则：

- 单文本分镜文档是权威的逐镜参考：叙事、构图、镜头运动、动作编排、每秒时间、镜头号都从这里取。已抽取的镜从独立节点取。若同时存在铅笔分镜图，仅用于人眼侧的姿态/剪影预检；不得让铅笔图覆盖文本分镜。
- 角色卡名为权威身份源（H3 用全局参考素材清单中的卡图作为身份源）。
- 场景卡名为权威环境源（H3 用全局参考素材清单中的卡图作为环境源）。
- **S01 片头标题段专属规则**：片名与署名在 S01 开头 3–5 秒内逐字复现，整段保持字体稳定、清晰可读，不得出现多余文字；段尾必须通过明确命名的段内转场转入 S01 剧情动作，剧情动作在同一镜头内开始。标题段引用的角色/场景保持主题化、非表演（静态环境 / 平静肖像 / 剪影 / 失焦身影），不得编排剧情动作；剧情动作阶段的在屏角色按正常规则表演。H3 下 S01 引用卡时写 Ref2VA；完全不引用卡时写 T2VA（已有批准 S01 首帧图时可用 I2VA）。若精确文字是交付重点，即使采用逐镜混合模式，S01 也优先用 H3；若动作调度迫使 S01 走 Seedance，则保留 S01 内的标题段并标注文字渲染风险，不得把片头拆成独立镜头。
- **剥离所有分镜双绑定标签**（`[char:…]`、`[scene:…]`、`[shot:…]`、`[dur:…]`、`[hook:…]`）再写视频提示词 — 这些是分镜专用参考标记，不能出现在最终视频提示词里。铅笔分镜图还自带镜头号、镜头图标、箭头和备注，写提示词时也要一并去除。**H3 Ref2VA 的 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` 是生成参考标签，不是分镜标签，必须保留。**
- 提示词只能描述风格锁下的干净全彩写实 CG 动画内容。
- 每条提示词末尾必须原样附加全局视觉风格锁的"风格锁核心词串"。
- 不要分镜线稿、不要手绘草图质感、不要标签、不要字幕（除非要求）、不要水印。
- 保持已批准的画面尺寸 / 比例和已批准的分辨率。

### 提示词格式选择

优先使用 `h3-prompt-writing` 技能生成每条单镜头视频提示词（这是首选格式，尤其面向 H3）。

- 若 `h3-prompt-writing` 技能可用，H3 必须按 full-reference 模式调用，从全局参考素材清单撰写每条单镜头 Ref2VA 提示词：六段顺序固定，`subject_definitions` 用卡图定义主体，`<Subject N>` 全局编号跨镜复用。Seedance 提示词按其基础结构撰写。
- 若 `h3-prompt-writing` 技能不存在，询问用户是否安装该技能，或 H3 按上方 Ref2VA 六段规则、Seedance 按下方默认规则生成。

### 模型相关 prompt 形态（h3-prompt-writing 不可用时的默认规则）

单文本分镜文档（已抽取的镜从独立节点取）同时喂两个模型，但包在分镜外的 prompt 前缀不同。H3 走 Ref2VA 时不套用下方的 H3 基础前缀，按六段 Ref2VA 结构撰写；风格锁核心词串仍原样追加：

- **H3 基础 prompt 前缀**（仅无卡 T2VA 回退时）：强调美术氛围、材质与体积光、粒子/雾效层次、动效与文字清晰度（如果相关）、双声道音频意图。H3 强在指令遵循，每秒指令可以几乎原文送入。追加：`国风仙侠影视级写实CG, next-gen game cinematic quality, desaturated moon-white and frost-blue palette, soft volumetric lighting, translucent silk backlight, strand-level hair detail, ink-wash mountain haze, shallow filmic depth of field, minimalist oriental negative-space composition, high-key low contrast, subtle film grain, restrained realistic performance`。
- **Seedance 2.0 prompt 前缀**（高动态回退）：强调电影感镜头语言、复杂调度、写实动作重量与惯性、布料与发丝的物理模拟、光位戏剧性、镜头选择。追加：`cinematic Chinese guofeng photoreal CG, realistic weighty performance, anticipation and follow-through, physically grounded cloth and hair simulation, dramatic backlit atmosphere, volumetric haze, lens-specific shallow depth of field, subtle film grain`。

用户选了逐镜混合时，按该行 `video_model` 字段匹配的前缀。

### 所有视频提示词写完后

按 S01、S02… 顺序把视频提示词作为文本节点放到画布，归组为 `<title> shot video prompts`；使用 H3 时把 `全局参考素材清单` 一并放在该组旁，然后展示用户选项卡：

- 批准提示词并交给视频生成工具（推荐）
- 重写选定提示词（可指定同一模型或切换）
- 修复角色不一致
- 修复场景不一致
- 加强分镜清理
- 修复跨镜头空间锚点漂移

## 边界

本 Skill 只产出提示词与规格，不生成图像、视频或成片。单张图、简单修图、单段镜头动画、logo 设计、单一独立提示词不用本 Skill。用户要实际生成图像或视频时，把产出的提示词交给对应的图像/视频生成工具或技能。
